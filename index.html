Respetar estas reglas garantiza consistencia visual y cumplimiento de la identidad de marca. Para el desarrollador: Nunca modificar los archivos SVG. Controlar el tamaño solo con width en CSS. Logo Artesanías de Colombia — Variantes oficiales Tres versiones según el fondo. Nunca usar una versión sobre un fondo incorrecto. Versión principal Ícono rojo + texto negro Para fondos blancos o claros Logo-ADC-04.svg Versión blanca Ícono blanco + texto blanco Para fondos rojos o muy oscuros Logo-ADC-06.svg Versión oscura Ícono rojo + texto blanco Para fondos grises oscuros o negros Logo-ADC-05.svg Versión horizontal — con nombre completo La versión horizontal incluye el texto "artesanías de colombia" junto al ícono. Para encabezados de documentos y materiales institucionales. ￼ Horizontal — texto negro Para fondos blancos o claros ￼ Horizontal — texto blanco Para fondos oscuros o negros Tamaños mínimos — Logo ADC Contexto Ancho mínimo Ancho recomendado Header principal del portal 80px 100px – 120px Footer 80px 100px – 110px Portada / hero 140px 160px – 200px Documentos y PDFs 100px 120px Usos incorrectos — Logo ADC ✕ No reflejar ni voltear Nunca espejado ni rotado. ✕ No distorsionar proporciones Siempre escalar proporcionalmente. ✕ No cambiar los colores No usar en escala de grises ni recolorear. ✕ No usar sobre fondos ajenos Solo sobre blanco, rojo o negro institucional. ✕ No reducir la opacidad Siempre al 100% de opacidad. ✕ No aplicar sombras o efectos Sin drop-shadow, glow, outline ni filtros. Zona de respeto: El logo siempre debe tener un espacio libre mínimo de 16px por cada lado. En documentos impresos equivale a la altura de la "a" del texto "artesanías". No deben unificarse. 01b CAPÍTULO Iconografía El portal usa la librería Lucide Icons como sistema oficial de íconos. Es una librería open-source con más de 1.000 íconos vectoriales SVG, consistentes en estilo y optimizados para interfaces digitales. ¿Por qué Lucide? Es la librería de íconos oficial de Shadcn/UI, el sistema de componentes que usa el portal. Todos los íconos tienen el mismo grosor de trazo, el mismo estilo visual y escalan perfectamente a cualquier tamaño. Lucide Icons Más de 1.000 íconos vectoriales SVG · Open source · Actualización constante lucide.dev Tamaños permitidos Los íconos siempre se usan en tamaños fijos. No usar tamaños intermedios ni arbitrarios. 16px Inline / texto size={16} 20px Botones / inputs size={20} 24px Navegación ★ size={24} default 32px Cards / destacados size={32} 48px Estados vacíos size={48} ★ 24px es el tamaño por defecto de Lucide. Usar este en la mayoría de casos salvo que el contexto requiera otro tamaño específico. Colores permitidos Los íconos heredan el color del texto en casi todos los casos. Solo en situaciones específicas se usan colores de la paleta institucional. Está siempre visible en el lado derecho de la pantalla y ofrece 4 controles que el ciudadano puede activar en cualquier momento para adaptar la visualización del portal a sus necesidades. Obligatorio para portales del Estado: Este componente es parte de los lineamientos de accesibilidad del Kit UI GOV.CO y debe estar presente en todas las páginas del portal, incluyendo páginas interiores. Si hay dudas sobre algún término, consultar con el equipo de diseño antes de implementar. #HEX Código hexadecimal de color. Ejemplo: #E30613 es el rojo de la marca. El desarrollador lo escribe tal cual en el CSS. px (píxeles) Unidad de medida en pantalla. Se usa para tamaños de fuente, padding, bordes y dimensiones de componentes. font-weight Grosor del texto. 400 = normal/regular, 600 = semi bold (títulos), 700 = bold/negrita. line-height Espaciado entre líneas de texto. Ejemplo: line-height: 22px significa 22px de alto por línea. border-radius Redondeo de las esquinas de un elemento. 0px = esquinas rectas, 6px = ligeramente redondeado, 50% = círculo. padding Espacio interior de un elemento, entre su contenido y su borde. Ejemplo: padding: 10px 20px = 10px arriba/abajo, 20px izquierda/derecha. box-shadow Sombra de un elemento. Crea la sensación de elevación (profundidad) en tarjetas y modales. CTA Call To Action (llamado a la acción). Es el botón principal de una sección. Siempre es el botón rojo primario. z-index Orden de apilamiento de elementos. Un número más alto = el elemento queda encima de los demás (como el panel de accesibilidad). object-fit: cover Propiedad CSS para imágenes. Hace que la imagen llene todo su contenedor sin distorsionarse, recortando los bordes si es necesario. rgba() Color con transparencia. El cuarto número (0 a 1) es la opacidad. Ej: rgba(0,0,0,0.13) = negro al 13% de opacidad. WCAG Pautas de accesibilidad web internacionales.
